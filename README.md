# Diabetes-Prediction-ML-Model

A Complete, Step-by-Step Teaching Notebook (with the Math Explained)

What you will learn in this notebook:<br>
How to load, clean and explore a real medical dataset
The mathematics behind 5 classification algorithms:
Logistic Regression
K-Nearest Neighbors (KNN)
Decision Tree
Random Forest
Support Vector Machine (SVM)
How to train, evaluate and compare these models
How to build a small interactive tool that asks the user for their health data and predicts whether they are likely to have diabetes
Dataset: diabetes_prediction_dataset.csv — 100,000 patient records with features such as age, BMI, blood glucose level, HbA1c level, hypertension, heart disease, smoking history, and gender. The target column diabetes is 1 (has diabetes) or 0 (does not).
