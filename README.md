# Diabetes-Prediction-ML-Model

A Complete, Step-by-Step Teaching Notebook (with the Math Explained)

What you will learn in this notebook:<br>
How to load, clean and explore a real medical dataset<br>
The mathematics behind 5 classification algorithms:<br>
Logistic Regression<br>
K-Nearest Neighbors (KNN)<br>
Decision Tree<br>
Random Forest<br>
Support Vector Machine (SVM)<br>
<br>
How to train, evaluate and compare these models?<br>
How to build a small interactive tool that asks the user for their health data and predicts whether they are likely to have diabetes
Dataset: diabetes_prediction_dataset.csv — 100,000 patient records with features such as age, BMI, blood glucose level, HbA1c level, hypertension, heart disease, smoking history, and gender.<br>
The target column diabetes is 1 (has diabetes) or 0 (does not).
